💻 How to Use Poquito in Your In-App UI Code

Choose the right format for your mobile & web architecture:

Method 1: Animated WebP (Zero Jitter · Recommended) 256px UI

Native GPU decoding on iOS & Android via standard Image component. 0 CPU overhead, 0 jitter, 100% transparent.

// React Native (iOS & Android)
import { Image } from 'react-native';

export const PoquitoMascot = () => (
  <Image
    source={require('../assets/poquito_front_talking_v2_clean_256.webp')}
    style={{ width: 120, height: 120 }}
    resizeMode="contain"
  />
);
Method 2: Parametric SVG Rig (Tab 2 · 3.2 KB) Pure Code

Zero raster images. Driven by state props ('idle' | 'listening' | 'transmitting' | 'dance').

// React Native / Web Vector Rig
import { PoquitoRig } from './PoquitoRig';

export const WalkieScreen = ({ isRecording, isPlaying }) => (
  <PoquitoRig
    model="talkie"
    state={isRecording ? "ptt" : isPlaying ? "rx" : "idle"}
    size={120}
  />
);

💡 Why the old auto-traced SVG was jittery: Frame-by-frame vectorizers generate ~100 distinct polygon paths per frame, causing subtle shape oscillations between frames. For in-app UI, always use Transparent 256px WebP (Method 1) or the Parametric Vector Rig (Method 2).
