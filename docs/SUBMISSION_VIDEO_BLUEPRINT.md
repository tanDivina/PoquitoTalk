## 🎯 Executive Narrative Architecture

The submission video weaves together four interlocking stories into an airtight 3-minute pitch:
1. **The Physical Reality & Problem (0:00 - 0:35)**: Why text translation fails in Bocas del Toro, Panama (noisy boat engines, wet hands, voice note culture).
2. **The 3-Pillar Product Philosophy (0:35 - 1:05)**: The user's core thesis—100% workflow on the expat, 0% friction on the contractor, ephemeral 2-way sessions.
3. **The Design Award Showcase (1:05 - 1:40)**: Caribbean terracotta palette, thumb-zone ergonomics, fanned rainbow card stack, and the zero-install tactile contractor HUD.
4. **The Live 2-Phone Walkie Demo (1:40 - 2:10)**: Real-time audio translation loop across Native App ↔ Mobile Browser with Voice Persona Asymmetry.
5. **The Layers Growth & Stripe Revenue Engine (2:10 - 2:40)**: Layers SDK attribution, viral referral loops, differentiated paywalls, and credit economics.
6. **Traction & Closing Call (2:40 - 3:00)**: Real community validation, production deployment, and the mic-drop takeaway.

## 🎨 Award Alignment Checklist for Judges

### 1. Layers Growth Award ($15,000 + Times Square Billboard)
- [x] **SDK Implementation**: `@layers/expo` v3.3.0 initialized via `src/services/layersService.ts` (`LAYERS_APP_ID: app_14732857b75e24a0`).
- [x] **RevenueCat Attribution**: Automated sync via `connectRevenueCat({ sdk: layersClient }, purchasesAdapter)`.
- [x] **WhatsApp Contagion Growth Loop**: Every outbound audio note and web walkie link exposes the product to local networks.
- [x] **Neighbor Referral Engine**: Live API endpoint (`/api/referral.php`) giving +5 credits per neighbor install, tracked on real-time admin telemetry.

### 2. Design Award
- [x] **Anti-AI-Slop Aesthetic**: Zero generic neon-dark cyberpunk templates; bespoke warm Caribbean terracotta (`#964824`), sand (`#FAF8F5`), and palm sage (`#4F604E`).
- [x] **Fanned Playing Cards Stack**: 12 categorized island trade decks resting 100% collapsed above the fold, expanding on tap along a falling rainbow spectrum.
- [x] **Tactile Contractor Web HUD**: Minimalist, high-contrast single green button (*"Mantenga presionado para hablar"*) built for non-technical field workers with wet hands.
- [x] **Paywall Salience Hierarchy**: Primary CTA rendered in unique Royal Indigo (`#4F46E5`) with zero color collisions across the entire UI.
- [x] **Crisp Vector SVGs**: Inline monoline vectors (`stroke-linecap="round"`), eliminating cartoonish emojis.

### 3. Funnel Vision Award (Stripe)
- [x] **Dual-Surface Commerce**: Native mobile subscriptions via RevenueCat + Web conversion funnel on `poquitotalk.hero-apps.com` via Stripe Checkout.
- [x] **High-Converting SKU Design**: $4.99 "Never Expires" credit packs (50 credits) + 7-Day Tourist Travel Passes ($4.99) for visitors.
- [x] **Fair-Use Credit Architecture**: 2-way live sessions stay in `waiting` state until the first voice message is transmitted, preventing accidental billing.
